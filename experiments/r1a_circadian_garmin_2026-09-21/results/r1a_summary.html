Cohort & label

  • s3 (Garmin) strict-coverage model union, n = 3,848; 70/15/15 → 2692/578/578 per repeat.
  • Label = recorded salutation, \(y{=}1 \Leftrightarrow\) female-form (2464/1384 = 64.0% prevalence).
  • Splits = the frozen FS-phase participant splits: SeedSequence([20260919, 3, r]), per-class permutation, test→val→train. Paired with every prior experiment (FS, FE, age, dayscale).

Input

artifacts_v2/epoch_hours.parquet, filtered channel = 3000 ∧ user ∈ cohort → 92,286 (user, hour-of-day) cells, coverage 1.0000. Schema (user, channel, hour ∈ {0..23}, n, vsum, vsumsq): per-user sums of all valid minute-observations grouped by local clock hour over the whole recording. Zero-cost source — the discovery that made R1a free.

Features (35 per user)

Per user, hourly mean and weight over the recording:

$$\bar h_k = \frac{\sum \texttt{vsum}}{\sum \texttt{n}}, \qquad n_k = \sum \texttt{n}, \qquad k = 0,\dots,23$$

Curve block (11). Weighted cosinor, 3 harmonics, weighted least squares with weights \(W=\operatorname{diag}(n_k)\):

$$\widehat{\mathrm{HR}}(k) = M + \sum_{j=1}^{3}\left[a_j\cos\!\left(\frac{2\pi jk}{24}\right) + b_j\sin\!\left(\frac{2\pi jk}{24}\right)\right], \qquad \hat\beta = (X^{\top}\! W X)^{-1} X^{\top}\! W\,\bar h$$

solved via lstsq (min-norm under rank deficiency). Emits: mesor \(M\); harmonic amplitudes \(A_j = \sqrt{a_j^2 + b_j^2}\) (24/12/8-h); acrophase

$$\mathrm{acro} = \arg\max_{t \in [0,24)} \widehat{\mathrm{HR}}(t)$$

evaluated on a 0.25-h grid (phase-convention-free), and goodness-of-fit

$$\mathrm{resid\_sd} = \sqrt{\frac{\sum_k n_k\left(\bar h_k - \widehat{\mathrm{HR}}(k)\right)^2}{\sum_k n_k}}$$

plus the curve summaries

$$\mathrm{night\_mean} = \frac{\sum_{k<6} n_k \bar h_k}{\sum_{k<6} n_k}, \qquad \mathrm{contrast} = \operatorname{wmean}(\bar h,\,8..19) - \operatorname{wmean}(\bar h,\,0..5), \qquad p_k \propto \left(\bar h_k - \min \bar h\right)^{+},\;\; H = -\sum_k p_k \ln p_k$$

with morning_slope = weighted-LS slope of \(\bar h_k\) on \(k\) over \(k \in \{5,\dots,9\}\) (bpm/h) and range \(= \max \bar h - \min \bar h\) over worn hours.

Raw profile (24). hour_h0..h23 \(= \bar h_k\), NaN where \(n_k = 0\) (structural; median-imputed downstream).

Wear-partialled variant (per repeat, OLS fit on train users only):

$$f_{\mathrm{resid}} = f - \left[\hat\gamma_0 + \sum_{k=0}^{22} \hat\gamma_k\, s_k + \hat\gamma_{23} \log n_{\mathrm{total}}\right], \qquad s_k = \frac{n_k}{\sum_k n_k}$$

i.e. each curve feature linearly residualised on its own hour-of-day coverage profile; residuals applied to all users (train-fit coefficients).

Protocol

  • Arms (5): BASE (FS-A1 replica), R1a_only, BASE⊕R1a, R1a_resid_only, BASE⊕R1a_resid.
  • Hygiene: SQPreprocessor on train (median impute + one-hot + indicators) → A1: drop __missing, caret nzv (dominant >95% ∧ unique/n < 10%). 400 cols BASE → 435 combined (no R1a column dropped).
  • Model: RF G1 @ 100 trees — max_features=0.4, min_samples_leaf=10, class_weight=balanced_subsample; seed SeedSequence([20260919, 3, r, 5]) — the same stream as FS/age, which is what makes BASE bit-exact.

Inference

Primary family: s3 all, two comparisons vs BASE, paired per repeat:

$$\Delta_r = \mathrm{AUROC}(\mathrm{arm},\,r) - \mathrm{AUROC}(\mathrm{BASE},\,r), \qquad r = 0,\dots,29$$ $$\bar\Delta \;\pm\; t_{0.9875,\,29}\; s\,/\sqrt{30}$$

Two 97.5% CIs ⇒ Bonferroni-simultaneous 95% family. Detection floor ≈ 0.003 AUROC (MC SE ≈ 0.0015).

Key findings

  • Both primary comparisons clear zero — the first feature-side lever past the detection floor since FS-phase saturation; same order as the age counter (+0.0029).
  • Standalone density: 35 curve features alone reach 0.6921, i.e. $\frac{0.6921-0.5}{0.7434-0.5} = 79\%$ of the participant-level excess signal.
  • Shape, not coverage: residualising the hour-of-day coverage profile out of each curve feature before addition raises the increment (+0.0036 vs +0.0029) — the added information is relative timing/form of the hourly profile, not wear volume. Coverage-partialling is a cheap denoiser worth carrying into R1b.
  • Direction is opposite to lab resting physiology (women: higher resting HR, earlier phase): male curves run hotter at every clock hour and peak earlier. The classifier is likely reading activity load / cohort composition / wear behaviour, not textbook circadian dimorphism. Label is recorded salutation, not biological sex/gender.
  • Positioning: the trait complement to dayscale’s state result. Participant level is near-saturated; the day level (base ≈ 0.65) has the headroom — R1b (per-day curves, weekday/weekend contrast, minute-scale dynamics, episodes) should be evaluated there first; its day-curve cache doubles as the D2 warm-start input.
